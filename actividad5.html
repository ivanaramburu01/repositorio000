Actividad 5

Servicio WEB Apache y Servicio FTP

✔ Servicio WEB Apache

  • Verificación del estado del servicio Apache.
  • Creación de una página web de prueba en /var/www/html.
  • Comprobación del funcionamiento desde navegador.

✔ Servicio FTP (vsftpd)

  • Instalación del servidor FTP vsftpd.
  • Edición del archivo de configuración /etc/vsftpd.conf.
  • Activación de chroot_local_user=YES y permisos seguros.
  • Reinicio y habilitación del servicio.
  • Prueba de acceso FTP desde explorador de archivos.
  • Creación y verificación de archivo de prueba.

El servicio quedó funcionando correctamente según la verificación final.
